# ClearCheck

Developed By :- Achint Kumar and Ankit Raj

Clear Check is an AI-powered, next-generation proctoring system designed to combat modern cheating techniques. It features advanced external device detection, real-time monitoring, and face liveness testing to prevent spoofing and unauthorized access. With multiple face detection, clipboard restrictions, and tamper-proof security measures, Clear Check ensures a secure and fair assessment environment. Designed with adaptive accessibility, it provides a seamless experience for all students while safeguarding academic integrity in the digital age.
